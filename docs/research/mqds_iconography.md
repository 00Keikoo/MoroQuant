## 1. Icon Library Mapping

MQDS maps core lifecycle stages to explicit Lucide/Heroicon names to maintain visual taxonomy across components.

| Lifecycle Node | Icon Identifier | Visual Meaning |
| :--- | :--- | :--- |
| **Dataset** | `database` / `table` | Database storage, data inputs. |
| **Feature** | `dna` / `cpu` | Formulated variables. |
| **Experiment** | `beaker` / `git-branch` | Isolated training attempts. |
| **Training** | `activity` / `refresh-cw` | Active model optimization. |
| **Validation** | `target` / `shield-check` | Out-of-sample quality verification. |
| **Calibration** | `trending-up` / `sliders` | Probability accuracy scaling. |
| **Backtest** | `clock` / `history` | Simulated execution runs. |
| **Paper** | `play-circle` / `test-tube` | Simulated live exchange testing. |
| **Execution** | `zap` / `bar-chart-2` | Slippage & latency analytics. |
| **Promotion** | `arrow-up-circle` / `award` | Stage gate verification checks. |
| **Production** | `server` / `shield-alert` | Live exchange deployment. |
| **Failure** | `x-circle` / `alert-octagon` | Execution error or verification reject. |
| **Warning** | `alert-triangle` | Model drift or slippage warning. |
| **Archived** | `archive` / `folder-minus` | Obsolete/superseded candidate. |
