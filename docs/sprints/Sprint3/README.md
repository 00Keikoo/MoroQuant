## Core Focus Areas

1. **Trade Explorer UI:** A unified interface for tracking, filtering, and debugging active and historical trades.
2. **Model Explainability:** Displaying the top features contributing to predictions on the dashboard.
3. **Alerting System:** A reliable Telegram bot that pushes signals, entries, and exits immediately.
