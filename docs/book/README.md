## Handbook Objective

This playbook documents **HOW** we develop the MoroQuant project. It provides:
- Clear guidelines for developers and AI agents to collaborate seamlessly.
- Quality gates to ensure codebase safety, reliability, and security.
- Standardized steps for continuous integration, auditing, and releases.
